# Website Presentasi Interaktif: Pancasila di Era Globalisasi (Minecraft Modern Theme)

Halaman landing page dan presentasi interaktif responsif bertema **Minecraft Modern** yang dirancang untuk materi pembelajaran PPKN: **"Pancasila di Era Globalisasi"**.

---

## 🎮 Fitur Unggulan

1. **Estetika Voxel & UI Minecraft Otentik:**
   - Palet warna resmi Minecraft: Hijau Rumput (`#5D8C3E`), Cokelat Tanah (`#6B4423`), Batu (`#7A7A7A`), Aksen Emerald (`#10B981`), dan Deep Slate/Obsidian (`#121212` / `#1E1E1E`).
   - Efek 3D inset/outset bevel pada tombol, slot inventaris, dan kontainer GUI.
   - Tipografi retro pixel Google Fonts: *Press Start 2P*, *Silkscreen*, dan *JetBrains Mono*.

2. **3D Voxel Interactive Hero Canvas:**
   - Ditenagai Three.js yang merender blok voxel mengambang (Grass block bertekstur prosedural, Emerald block, Diamond block, Gold block).
   - Efek parallax interaktif halus mengikuti pergerakan kursor mouse dan rotasi 3D.
   - Partikel pengalaman (*XP green orbs*) mengambang di atmosfer.

3. **Hotbar Navigasi 9 Slot (Bottom Dock):**
   - 7 slot materi presentasi langsung, 1 slot pengubah mode tampilan, dan 1 slot buku panduan/identitas.
   - Indikator slot aktif dengan kilau emerald dan tooltip item bergaya Minecraft ungu legendaris.
   - Dukungan penuh tombol angka keyboard `1` s.d. `7` untuk melompat seketika ke slide yang diinginkan.

4. **Crafting Table & Server GUI (Slide 5):**
   - Sintesis dialektika Peluang + Risiko = Sikap Kritis (*The Shield of Reason / Rarity Legendary*).
   - Tabel status server Minecraft dengan indikator latensi ping dan spesifikasi buff/debuff.

5. **Dua Mode Presentasi Fleksibel:**
   - **Mode Slide:** Mode presentasi per-layar penuh (*slide-by-slide*) dengan transisi mulus.
   - **Mode Scroll:** Mode landing page panjang (*continuous scroll*) dengan pembaruan otomatis slot hotbar dan bilah XP.

6. **Audio FX Prosedural (Web Audio API):**
   - Suara klik mekanis UI Minecraft dan suara jingle kenaikan level (*level-up chime*) tanpa ketergantungan file eksternal.
   - Tombol toggle suara (Mute / Unmute) dan pintasan tombol `M`.

---

## ⌨️ Pintasan Keyboard (Hotkeys)

| Tombol | Fungsi |
|---|---|
| `1` - `7` | Langsung menuju Slide 1 sampai Slide 7 |
| `→` / `Space` / `PageDown` | Slide berikutnya (*Next Slide*) |
| `←` / `PageUp` | Slide sebelumnya (*Prev Slide*) |
| `V` / `8` | Beralih antara Mode Slide dan Mode Scroll |
| `M` | Matikan / Hidupkan efek suara (*SFX*) |
| `I` / `9` | Buka / Tutup buku info identitas penyaji (*Book & Quill*) |
| `Esc` | Menutup jendela modal aktif |
